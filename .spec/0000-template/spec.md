# Spec-0000: Título curto da feature

## Problema

O que precisa existir e para quem, em um parágrafo. Se a feature vem de uma
conversa ou decisão, referenciar a ADR ou o spike de origem.

## Requisitos

Formato: QUANDO [condição], O SISTEMA DEVE [comportamento observável].

- R1 — QUANDO ..., O SISTEMA DEVE ...
- R2 — ...

## Regras de negócio

- RN1 — a regra, e de onde ela vem (decisão de produto, ADR, obrigação legal).

## Critérios de aceite

Cada um verificável por comando ou requisição — é o que a seção "Como foi
testado" do PR vai provar.
