# Spikes

Investigações registradas: cada estudo que sustenta uma decisão do projeto vira um
documento numerado aqui. A diferença para as [ADRs](../adrs/) é o papel — o spike
investiga e recomenda; a ADR decide. Quando uma investigação resulta em decisão, a
ADR correspondente aponta para o spike que a sustentou.

Regras de uso:

- Um spike responde **uma pergunta**, declarada no topo do documento.
- Todo número vem com a marcação do que é verificado em fonte oficial e do que é
  estimativa.
- O que ficou fora da investigação é dito no final — omissão declarada em vez de
  completude aparente.
- Todo valor marcado [verificado] tem a fonte linkada na seção de referências, com
  a data da consulta.

Para criar um novo, copie o [template](0000-template.md).
